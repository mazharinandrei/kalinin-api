# Kalinin API
API для чат-бота

## Методы API:
- GET /roll_dice: кинуть кубик d20 и получить трактовку выпаденного значения;
- POST /brick-translate: перевести текст на кирпичный язык;
- POST /messages: получить ответ на текстовое сообщение;

## Установка
1. Склонировать репозиторий:
```sh
git clone https://github.com/mazharinandrei/kalinin-api.git
```

2. Установить зависимости:
```sh
uv sync
```

3. Заполнить `.env` файл (пример в `.env.template`), в котором настраивается подключение к БД 

4. Выполнить миграции:
```sh
alembic upgrade head
```

5. Запустить проект
```sh
uv run main.py
```

6. На адресе http://localhost:8000/docs можно ознакомиться с документацией, а также заполнить базу данных сообщениями
POST /universal-replies -- добавить универсальный ответ (выбирается случайным образом, если нет ответа по триггеру)
POST /rules -- добавить правило ответов (если в сообщении присутствует один из триггеров, указанных в правиле, в качестве ответа может быть выбран один из указанных в правиле ответов)
POST /roll_dice_ranges -- добавить трактовку диапазона для подбрасывания кубика d20  (начало диапазона, конец диапазона, текст трактовки)
